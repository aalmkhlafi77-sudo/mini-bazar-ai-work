# Mini Bazar AI Work — بيئة عمل تطويرية

مستودع مرافق لتطوير Mini Bazar والعمل بين أدوات الذكاء الاصطناعي والمشروع؛ يحتوي على بنية React/Vite ووثائق Firebase وHostinger.

## التشغيل والتطوير

`npm run dev` للتطوير و`npm run build` للبناء. لا يُفترض أن هذه نسخة الإنتاج.

## ملاحظات

هذا الوصف مستند إلى بنية المستودع ولا يؤكد اكتمال جميع الوظائف أو نجاح النشر. لا ترفع أسرار البيئة إلى GitHub.
